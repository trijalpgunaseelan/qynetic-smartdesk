Add SmartDesk Auto SyncAdd Battery Sync

Install Scriptable on your iPhone, add the downloaded script as SmartDesk Sync, and run it once. Enter this desk's address and access token; allow Calendar and Local Network access. For hands-off updates, use iPhone Shortcuts automations: Charger connected/disconnected and Battery Level → Run Scriptable SmartDesk Sync with parameter battery; Calendar app closed and a morning Time of Day → parameter both. Choose Run Immediately. Keep the hotspot enabled.

Shortcut import rejected? Set up without a file
  1. In Shortcuts, tap + and name it SmartDesk Auto Sync.
  2. Add Wait for 2 seconds.
  3. Add Scriptable → Run Script, select your SmartDesk Sync script, and set Parameter to both. Disable Run in App if shown.
  4. Run once to allow permissions. Duplicate as SmartDesk Battery Sync with Parameter battery.
  5. Under Automation, use Charger connected/disconnected → Run Immediately → Run Shortcut → SmartDesk Battery Sync. Use Calendar app closed and a morning trigger for SmartDesk Auto Sync.

This creates the shortcuts directly on your phone; no file import is required.
